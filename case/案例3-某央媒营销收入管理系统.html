某央媒 · 营销收入管理系统

用钉钉宜搭低代码，把分散的收入数据变成可查、可比、可控的经营看板

行业：新闻 / 媒体 平台：钉钉宜搭 交付：一人独立搭建 类型：营收管理 / 数据汇总

项目背景

同一央媒客户的第二个系统——营销收入管理。该机构日常涉及多维度营销收入（实际到账、测算后收入、用户增长等），过去这些数据散落在各处表格中，管理层难以实时掌握经营全貌。

核心痛点

· 收入数据散落：各部门各自维护 Excel 表格，格式不统一、口径不一致；
· 汇总靠手工：月底专人收集各部门数据、手动拼表，耗时且易出错；
· 多维度难交叉：想按人 / 部门 / 时间 / 收入类型交叉查询，基本做不到；
· 审批无留痕：收入提报和修改缺少流程管控，谁改了什么、何时改的，追溯困难。

解决方案

基于钉钉宜搭搭建一体化营销收入管理平台，覆盖从员工提报到多层级汇总的全链路：

员工提报
→
审核确认
→
自动汇总
→
多维筛选

员工端（首页）

移动端随时发起营销收入提报；个人汇总页面查看自己的收入明细与统计。

管理后台

管理员统一处理待办、修改/删除记录、发起提报，拥有完整的数据治理权限。

统计汇总（全局）

按部门/姓名/时间多维度筛选，展示实际到账总收入、测算后营销总收入、新增/续签用户数等多指标。

部门 / 个人汇总

分别按部门和个人的视角展示收入明细，支持分页浏览与导出。

系统截图

↑ 管理后台：待处理 / 我创建的 / 抄送我的 + 修改/删除/提报管理 + 汇总入口
↑ 员工首页：申请管理（营销收入提报）+ 档案管理（个人/部门汇总）
↑ 营销收入汇总（全局）：按年月/姓名/部门筛选，多列指标一览
↑ 个人营销收入汇总：每位员工的收入明细与分页浏览
↑ 部门营销收入汇总：按部门维度的收入统计与对比

价值成效

数据集中化

所有收入数据一个平台，告别 Excel 散落。

多维可查

按人 / 部门 / 时间 / 类型自由组合筛选，秒出结果。

流程合规

提报→审核→入账全程留痕，每笔收入可追溯。

分层视图

员工看自己、部门看团队、管理层看全局，各取所需。
